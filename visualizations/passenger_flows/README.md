# September 2026 passenger flows

This directory owns the second half of the presentation. It reads committed cleaned inputs and writes only passenger-flow outputs. No cleaning pipeline or teammate notebook is run.

## Environment and inputs

Use Python 3.11+ (the validator uses starred tuple subscripts), pandas, NumPy, Matplotlib and Pillow. Root requirements include pandas and Matplotlib, which install NumPy and Pillow transitively. Tested: Python 3.11.4, pandas 2.2.2, NumPy 1.23.5, Matplotlib 3.10.1 and Pillow 10.3.0. Environment setup is separate from validation.

Install Arial for the approved appearance. Shared setup logs the selected font and falls back to Liberation Sans or DejaVu Sans when absent. MP4 generation requires FFmpeg with libx264 on PATH. Full validation also requires FFprobe on PATH. The supplied clips used FFmpeg 7.1; these executables are not installed by pip requirements.

Exact tracked inputs:
- data/clean/stations.csv: station codes, names, types, coordinates and regions.
- data/clean/od_hourly.csv: origin_code, destination_code, day_type, hour, trips and trips_per_day.
- data/clean/station_hourly.csv: station_code, day_type, hour, tap_in, tap_out and net.
- data/clean/od_region.csv: regional totals for Sankey and independent validation.
- data/reference/ura_mp2019_region_boundary.geojson: map boundaries.

No API key or raw-data extraction is needed. Paths resolve from source files. Run commands from the repository root.

## Fresh-checkout reproduction

From a checkout containing the proposed source and artifact manifest:

~~~powershell
python -B -m visualizations.passenger_flows.flow_map
python -B -m visualizations.passenger_flows.sankey
python -B -m visualizations.passenger_flows.diverging_bar
python -B -m visualizations.passenger_flows.slopegraph
python -B -m visualizations.passenger_flows.validate_outputs --static --no-write
python -B -m visualizations.passenger_flows.animate --all
python -B -m visualizations.passenger_flows.validate_outputs --full --no-write
~~~

All four static modules also support direct execution, e.g. python -B visualizations/passenger_flows/sankey.py. The animation module uses package execution.

Static mode is the default: all static tables, 14 PNGs and numerical invariants are checked without requiring MP4s or FFmpeg. Full mode includes all static checks plus four MP4s. Without --no-write, either mode overwrites VALIDATION.md and validation_summary.json, recording its mode. Use full mode for delivery reports.

Animations recompute from cleaned inputs. Existing station_net_movement.csv and station_rank_changes.csv are optional cross-checks: mismatches fail when present; absence does not prevent rendering.

Current static scripts regenerate 11 current PNGs and nine tables. Three historical PNGs (slopegraph_original_six.png, backup/top10_weekday.png, backup/top10_weekend.png) and top10_station_rankings.csv are preserved audit artifacts, not regenerated by current scripts. Include them in the manifest for complete validation on a fresh checkout. Animations require none of these output files.

For isolated animation exports:
~~~powershell
python -B -m visualizations.passenger_flows.animate --all --output-dir <temporary-directory>
~~~

## Current visual encodings

All 14 PNGs are opaque 1280 x 720. Four MP4s are silent H.264/yuv420p, 1280 x 720, 15 fps. Background #0E0E0E; blue #7296B8, teal #69A89F, amber #D6A45D.

Both maps use the same top 15 directed OD pairs, monthly trips descending with origin/destination code tie-breaks. Daily volume = monthly trips / 30. Shaft width = daily volume / 1000 points; arrowhead mutation scale = 3.5 times shaft width. Opposite directions use separated curves, not physical rail routes.

- flow_map.png: only Tampines to Pasir Ris is amber; ordinary links blue. Blue legend samples approximately 4,000, 5,000 and 6,000.
- flow_map_volume_categories.png: ranks 11-15 blue, 6-10 teal, 1-5 amber. Corresponding colored samples approximately 4,000, 4,500 and 6,000. Categories refer only to the displayed 15.
- Both legends say Average daily trips, at figure y=0.889, approximately 10-12 pixels above the map boundary.
- Map axes [0.005, 0.015, 0.99, 0.96], 8% endpoint padding. Longitude 103.686603-103.968714; latitude 1.295842-1.413229. Cosine correction preserves geographic aspect and introduces vertical letterboxing.

Diverging bars show six morning-selected stations: three largest positive and three most negative weekday net values. Net into station surroundings = (tap-outs minus tap-ins) / 22. Morning bins 7,8,9; evening bins 17,18,19. Teal positive, amber negative. Shared limits -45,000 to 45,000.

Slopegraph: union of weekday and weekend/holiday top fives, eight stations with global competition ranks among 184. Activity = tap-ins + tap-outs divided by 22 or 8. Ranks 1-16 uniformly spaced; rank 48 maps to display position 19 with an explicit break skipping 17-47. Cross-break distances and angles are not proportional rank differences. Raffles Place amber, City Hall teal, others blue.

Sankey: all 25 regional directions, including within-region journeys. Destination buckets are each region's top three receiving stations plus Other. Origin attribution is retained in tables. Never add journey volumes across stages.

## Interpretation limits

One aggregate MRT/LRT month does not measure unique passengers, purpose, physical routes, duration or daily variability. OD hour is departure time. Gate balances omit some interchange transfers and do not establish residential/work status. Animation visibility and drawing progress are presentation effects; bar interpolation is not observed intermediate-hour data.
